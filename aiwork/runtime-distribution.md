# 首版运行环境与分发

日期：2026-10-21。

历史技术选型记录；当前rc.1本地候选、已实现能力及未验环境以根README、docs和本轮任务交接为准，下方早期门槛不作为当前未构建结论。

原阶段状态：用户已确认改为便携发布，替代此前 NSIS 当前用户安装方案。TASK-001 已生成 Windows x64 工程并通过独立生产构建；人工桌面验收待用户结果，正式发布包、Windows 11 及缺失 Runtime 场景未验证。

## 已确认约定

| 项目 | 首版选择 |
| --- | --- |
| 操作系统 | 最低 Windows 10 22H2，同时面向 Windows 11；分别记录实际验证结果。 |
| 工具架构 | 仅交付 x64，Rust 目标为 `x86_64-pc-windows-msvc`。 |
| WebView2 | 使用共享 Evergreen Runtime，复用符合要求的已安装运行时。 |
| 使用方式 | 解压到用户选择的可写目录，直接运行 `ClickMaster.exe`，无需安装本工具。 |
| 数据位置 | EXE 同级 `data/`，详见 [本地数据](local-data.md)。 |
| 缺失运行时 | 不自动下载或安装；发布前明确原生错误提示与官方获取入口。 |
| 发布路线 | 构建 x64 EXE，关闭 Tauri 安装器打包；不交付 NSIS/MSI。 |

上述为工具的发布范围，不将目标 EXE 的位数作为默认筛选条件；不同位数目标的具体选择与消息行为仍需实测。

## WebView2 选择依据

| 方案 | 包体与网络取舍 | 本项目决定 |
| --- | --- | --- |
| 原生 EXE + 共享 Evergreen | 无需安装本工具、发布体积较小；要求已有兼容运行时 | 用户确认，进入集成规划；实际依赖闭包待验证 |
| NSIS + 下载或嵌入 bootstrapper | 可补装运行时，但需要安装流程 | 被便携需求替代，原 `downloadBootstrapper` 决策不再适用 |
| 嵌入离线安装器 | 可离线补装运行时，但增大安装包 | 延后，首版不承诺完整离线安装 |
| 固定版本运行时 | 应用携带运行时，包体与更新维护成本增加 | 不采用 |
| 缺失运行时提示 | 依赖已有运行时，缺失时停止并提供说明 | 待明确并验证原生启动提示，不能依赖尚未创建的 WebView 页面 |

以上取舍依据官方资料，未测量本项目包体。Evergreen Runtime 按 Microsoft 的更新机制维护；它的安装与更新联网行为应与本工具的本地功能区分，不承诺整个运行环境永不联网。

免安装指本工具无需安装，不等于无运行时依赖。共享 Runtime 的安装与更新位置由系统管理，可能使用系统盘；不得清理其他应用共用的运行时，也不承诺操作系统或第三方组件绝不产生额外文件。

## 便携路线门槛

| 门槛 | 状态与依据 |
| --- | --- |
| 目标环境与构建路径 | pass（资料）：沿用 Windows/MSVC；Tauri CLI 提供 `--no-bundle`，实际构建未执行 |
| 数据范围与排除 | pass（设计）：EXE 同级数据，开发/验收隔离，发布包排除用户数据 |
| 权限与网络副作用 | pass（设计）：可写目录、失败不回退系统盘、不提权、不自动补装依赖 |
| 重复构建、迁移与移除 | defer：锁定依赖、目录移动和保留配置升级仍需实测 |
| 集成与维护边界 | pass（设计）：不新增框架，Runtime 仍由系统维护 |
| 相对原方案优势 | pass（需求）：满足直接运行与数据跟随程序，省去本工具安装步骤 |

当前决定为批准进入集成规划。资料与设计门槛不代替运行或发布验证；本次不下载依赖或启动工程开发。

## 验证与剩余工作

- 按实际依赖组合核对最低 WebView2 版本，避免“运行时存在”被误当成“版本满足要求”。
- Windows 10 22H2 与 Windows 11 分开记录启动、窗口交互和后台输入结果；支持目标不等于兼容性已通过。
- 检查已有、缺失及版本不足 Runtime 的行为；原生错误提示及官方获取入口待发布设计明确，首版不自动补装。
- 核对 EXE 旁实际必需文件，不预先承诺仅有单个 EXE；在独立可写目录验证解压启动、中文/空格路径及不同工作目录。
- 创建 WebView 前设置用户数据目录，检查未落入默认用户目录；验证不可写目录提示、移动整个目录和保留 `data/` 的升级。
- 具体依赖版本、运行日志保留预算与轻量化预算仍待落实。
- 主要分发格式建议为便携 ZIP，命名与清单在发布任务明确；保留数量见 [release](../release/README.md)，本次没有生成或晋级产物。
