# 开发与测试产物落点

日期：2026-10-21。用户已确认：中间产物、测试产物等均留在当前工作文件夹，不随意写入系统盘或其他盘。

## 适用范围

- 本项目开发、依赖下载、构建、调试、自动化测试和验收生成的文件，统一位于 `<repository-root>` 内；不能仅因路径可写就使用外部目录。
- 不使用系统临时目录、用户下载目录、用户默认包缓存、外部工作树或会话可视化目录保存本任务新增产物。
- 读取现有系统工具链、运行时与用户配置不等于允许修改这些位置；不安装或更新全局工具、不更改用户级环境变量或包管理器配置。
- 操作系统、已有共享 Runtime 与执行平台本身的内部记录不能伪称由本项目完全控制；发现依赖工具有无法重定向的项目相关外写时，停止相应步骤并说明，不默认豁免或继续。

## 目录与进程环境

| 内容 | 项目内位置与设置 |
| --- | --- |
| 临时文件 | `build/tmp/`；启动子进程前按进程设置 `TEMP`、`TMP`，工具需要时设置 `TMPDIR` |
| npm 下载缓存与诊断 | `build/cache/npm/`；显式传参或设置进程 `npm_config_cache` |
| Cargo registry/git 数据 | `build/cache/cargo-home/`；进程 `CARGO_HOME`，不改变已有 Rust 工具链位置 |
| Rust 编译输出 | `build/cargo/`；进程 `CARGO_TARGET_DIR` |
| 可选 Node 编译缓存 | `build/cache/node/`；使用时按进程指定 `NODE_COMPILE_CACHE` |
| 前端依赖与构建 | 根级 `node_modules/` 与 `build/frontend/` |
| 开发运行数据 | `build/runtime/dev/` |
| 测试、截图、临时脚本、配置夹具及验收副本 | `build/verification/<task-id>/`，按 Coder/Verifier 区分输出 |
| 普通日志 | `build/logs/`，写入前脱敏；长期必要摘要放 `aiwork/` |

环境由统一脚本按项目根解析并传给子进程，包括依赖安装与隔离验收；不能只在构建命令设置，遗漏 npm 安装、测试或编译辅助进程。不重定义 `HOME`、`USERPROFILE` 或现有工具链根路径以假装隔离。新增工具若另有缓存/输出参数，执行前一并确认。

生产便携程序仍使用 EXE 同级 `data/`；本轮生产运行验证仅在项目内隔离目录进行，不能复制到外部临时目录。开发服务器及验证辅助进程仅使用本项目路径。

## 交接与验收

- Coder 提供实际命令、工作目录、进程级目录设置和生成路径清单；正文使用相对路径或占位符。
- Verifier 检查统一入口及下游调用是否继承设置，运行前后核对受管理输出；没有系统级监控证据时，不宣称已证明整个系统零外部写入。
- 忽略规则不代替脱敏与保留规则；不因发现目录外残留就删除未知文件或清理外部缓存。
- 本约定适用于后续任务，只有用户明确变更后才能例外执行。
