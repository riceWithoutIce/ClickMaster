## Findings

每个问题填写以下字段；无问题则写“本次范围内未发现 findings”，保留未执行项。

- 编号 / 级别（BLOCKER 或 FOLLOW-UP）：
- 对应需求 / 位置：
- 复现条件 / 实际与预期：
- 用户影响 / 证据：
- 建议：
- 用户决定（当前修复 / 延期 / 接受风险，未决定前注明）：

## 证据边界与复审

- 未执行项 / 证据不足项 / 目标游戏与发布状态：
- 脱敏检查范围 / 结果 / 未覆盖项（不填写敏感原文）：
- 用户批准修复的原 finding / 新快照：
- 原 finding 及紧邻回归结果：
- 剩余延期项 / 已接受风险：
- 是否满足停止条件 / 尚未通过的门槛：
