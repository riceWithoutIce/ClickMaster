## 工程与版本

- 使用已选主要版本 Tauri 2、Vue 3、TS、Vite 和 npm。Coder 安装前核对官方模板/注册表元数据及 Node/Rust 兼容要求，记录实际选择的具体版本，再生成并跟踪前端与 Cargo 锁文件；不混用包管理器。

- 采用 x64 便携 EXE 路线，构建时关闭安装器打包，不配置原 NSIS/`currentUser`/`downloadBootstrapper` 方案，不下载 NSIS/WiX 或运行 WebView2 安装器。

## 界面基线

- 使用系统标题栏，支持关闭、最小化、还原和缩放；关闭按钮退出，最小化按下述规则处理；不承诺 Windows 10/11 外框圆角效果一致。
- 使用已确认的紧凑纵向布局、中性配色、圆角表单/面板与简短反馈；使用 CSS 变量和组件局部样式，尊重减少动效设置。
- 布局包括目标区域、输入配置区域、运行控制区域、状态区域；输入方式展示左键、右键、键盘三个选项。
- X/Y 与按键区域可随所选模式切换展示；本轮不录入真实目标或发出输入，未实现的绑定、测试、开始与停止动作禁用。
- 显示“未绑定”“未运行”等真实初始状态；应用版本取自 Rust 只读命令，不将硬编码字符串当作通信验证。
- 常见缩放下主要文字与控件可见，键盘 Tab 导航、焦点样式和控件标签可用。视觉精修与复杂动效后续另行设计。

## 托盘与最小化偏好

- 应用运行时保留托盘入口；左键点击还原并显示主窗口，右键菜单提供“打开主窗口”“停止”“退出”。本轮无输入任务，“停止”禁用，不模拟停止成功。
- 默认最小化隐藏主窗口并移除任务栏图标；开启“最小化时保留任务栏图标”后执行常规最小化，托盘入口仍存在。窗口恢复显示时正常保留任务栏图标。
- 主窗口提供上述偏好开关，修改并保存成功后再作为当前有效偏好；启动读取偏好，但总以可见窗口和未运行状态进入，不自动收起或执行。
- 关闭按钮与托盘“退出”结束本工具并移除自身托盘图标；只处理自身窗口、线程和资源，不结束任何外部应用。
- 托盘初始化失败时保持可见窗口并显示原因，不能隐藏成不可恢复状态；此时最小化回退到普通任务栏最小化，并提示托盘功能不可用。
- 缺失配置使用默认值；非法配置不静默覆盖原文件，显示原因并使用默认偏好。保存采用临时文件与替换等避免半写入的方式；失败显示错误，保留原文件和上次有效偏好，不回退其他数据目录。
- 默认偏好为不保留任务栏图标；其他未知配置字段和业务输入参数不在本轮写入范围。同目录多实例策略仍留后续设计，本轮不同时启动多个副本写同一配置。
