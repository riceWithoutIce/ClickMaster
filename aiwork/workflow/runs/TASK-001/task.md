## 目标与依据

建立可重复构建、可直接运行的 Windows x64 Tauri 工程，呈现紧凑纵向界面，完成托盘、最小化偏好及便携数据目录，并验证真实前后端通信。为下一任务的窗口枚举与后台输入提供基础。

- 已确认技术：[Vue 3 + TS + Vite + npm](../../../frontend-selection.md)、Tauri 2 + Rust。
- 已确认环境：[Windows 10 22H2 / Windows 11 x64、Evergreen WebView2、免安装便携发布](../../../runtime-distribution.md)。
- 功能依据：[冻结需求](../../../requirements.md)。本任务只提供 R01–R10 的界面承载，不宣称任何输入功能已实现。
- 设计与数据落点见 [工程边界](engineering.md)，逐项验收见 [验收清单](acceptance.md)。

## 本轮交付

1. 在仓库根初始化 Vue 3 + TS + Vite，保留根级 `src/` 与 `src-tauri/` 官方常用布局。
2. 建立有效的 Tauri/Rust 入口、配置、最小必要能力声明及构建所需图标资产；替换模板演示内容，不加入业务无关插件。
3. 提供统一的开发、类型检查、前端构建和不打安装包的桌面构建入口，固定依赖与构建输出位置。
4. 实现目标选择、输入配置、运行控制、状态四个界面区域；未实现的执行能力禁用，不能显示虚假的发送成功或运行中。
5. 通过一个只读 Rust 命令取得应用版本并在界面显示，验证真实 IPC；失败时显示初始化异常。
6. 实现托盘及窗口生命周期：默认最小化到托盘、不留任务栏图标；可选择保留任务栏图标；恢复显示窗口时正常显示任务栏图标；关闭按钮和托盘退出均结束程序。
7. 保存并恢复“最小化时保留任务栏图标”偏好，接入 EXE 同级数据和开发隔离目录；不保存业务输入参数，不恢复运行状态或绑定。
8. 完成桌面启动、托盘、窗口交互和偏好重启验证，交付稳定快照、使用命令及准确的验收证据。
