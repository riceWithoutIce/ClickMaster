# TASK-015：0.1.0 首版发布准备

## 目标

以已验收的 `0.1.0-rc.9` 为功能基线，准备首个正式版 `0.1.0` 的文档、版本、构建和人工验收流程。

用户已确认首版发布范围：Windows x64 免安装 ZIP，解压后直接运行；数据写入 EXE 同级 `data/`；使用共享 Evergreen WebView2；正式发布前继续保留已知限制和未验证边界。

## 冻结范围

- 交付文件：`ClickMaster-0.1.0-windows-x64.zip`。
- 版本源：`version/VERSION`，同步 package、Cargo、锁文件自有包和 Tauri 配置。
- 使用说明、已知限制、变更记录和发布索引必须与正式版状态一致。
- 发布索引仅在正式包验收通过后新增 `0.1.0` 条目。
- 发布后按保留规则只保留最新正式二进制，历史版本保留元数据、哈希和验收记录。

## 允许修改

- `version/`、`docs/`、`README.md`、发布相关 `release/` 文档。
- 本任务目录内的记录、构建清单、来源和验收回执。
- 为版本同步所需的 `package.json`、`package-lock.json`、`src-tauri/Cargo.toml`、`src-tauri/Cargo.lock`、`src-tauri/tauri.conf.json` 元数据。
- 正式包准备所需的项目内构建输出；输出不纳入 Git。

## 排除项

- 不新增功能，不修改输入通道、IPC、worker、停止、托盘或 UI 行为。
- 不处理已延期的 OVERLAY-001、F-01、真实性能优化和通用游戏兼容性。
- 未完成人工验收前不创建正式版标签、不发布 GitHub Release、不淘汰 rc.9。
- 不承诺任意游戏、最小化窗口、缺失/旧 WebView2 Runtime 或跨系统环境兼容。
