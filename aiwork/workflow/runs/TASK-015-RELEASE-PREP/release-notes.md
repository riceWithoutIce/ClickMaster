# ClickMaster 0.1.0

首个正式版本，已完成用户人工回归。

首个正式版，提供 Windows x64 免安装 ZIP。解压到可写目录后运行 `ClickMaster.exe`，数据写入同级 `data/`；需要已有兼容的 Microsoft Evergreen WebView2。

- 按 EXE、标题或 PID 筛选并绑定目标窗口，支持显示后台窗口。
- 可选窗口消息或已核验 TapTapLoot 版本的专用 IPC。消息支持左键、右键、单键及客户区坐标。
- 单次/重复、固定/随机间隔、永久/限时执行；按钮、F8、托盘停止，最小化可收起至托盘。
- 浅色图标导航、分页面参数、按需诊断与可选性能日志。

## 使用边界

- 窗口消息投递、IPC 已发送均不等于游戏玩法响应；专用 IPC 不代表任意游戏兼容。
- 1～60000 毫秒为每次完整操作后的额外等待，默认 2000；1 毫秒仅供边界测试，不承诺 1kHz、30/60 次玩法事件或帧同步。
- 目标保持非最小化。已发送操作不能撤回，停止后游戏可能继续处理缓冲。
- 当前未签名，Windows 可能提示。面向 Windows 10 22H2 / Windows 11 x64；Windows 11、缺失/旧 WebView2 和长期性能没有本版专项验证。
- 实验坐标覆盖层、切换选择时的绑定标签及性能后续项尚未修复，详见包内 `docs/LIMITATIONS.md`。
