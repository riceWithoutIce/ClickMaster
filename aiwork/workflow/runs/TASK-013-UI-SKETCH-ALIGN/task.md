# TASK-013：UI 草图内容对齐

## 目标

在保留浅色主题的前提下，将当前 UI 的布局、信息层级和诊断入口对齐已确认的草图。

## 冻结范围

对照基准：`build/verification/ui-sidebar/clickmaster-user-ui.html`，本轮沿用浅色主题，只对齐该草图的结构、文案层级和交互入口。

- 保留现有浅色主题，不做主题切换。
- 主页面只保留用户日常操作所需控件。
- 输入方式页移除常驻的 IPC、身份核验和读取诊断说明，技术信息进入诊断入口。
- 执行参数页收紧说明和间距，保留重复间隔、执行时长和必要状态。
- 目标窗口页减少常驻说明和噪声，技术字段继续放入详情。
- 诊断信息改为底部独立入口，打开浮层或抽屉，不占用主内容流高度。
- 侧栏、顶部状态、底部操作区的层级和间距对齐草图，保留现有功能。
- 页面标题去除面包屑，提供按需页面帮助；目标页搜索与刷新同排，绑定状态及操作集中呈现。
- 重复间隔采用分组标题、帮助入口、输入框内单位和动态简短等待说明；限时字段按需显示。
- 消息模式采用点击位置选择；客户区中心时隐藏自定义 X/Y 字段。
- 底部采用更多菜单进入诊断对话框；对话框支持关闭、Escape 和焦点返回，不能影响 F8 停止。

## 排除项

- 不修改浅色主题、IPC 协议、worker 生命周期、输入语义、性能逻辑和依赖。
- 不删除诊断日志、错误、IPC 状态、执行摘要或日志入口。
- 不修改托盘、F8、窗口绑定和执行行为。
- 不提交、推送或正式发布。
