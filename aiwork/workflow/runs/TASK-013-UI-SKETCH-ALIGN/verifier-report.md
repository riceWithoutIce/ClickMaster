## 一次性 Findings

### F-01：选择新目标时，“已绑定”仍可能指向原目标（P2 / FOLLOW-UP）

位置：`src/App.vue:336`。

已绑定 A 后，在目标列表选中尚未绑定的 B，当前 `binding-label` 仅判断 `bindingStatus.bound`，因此 B 下方仍显示“已绑定”，旁边又出现“绑定窗口”。草图只在所选目标等于绑定目标时显示该标签。顶部仍正确显示 A，后端绑定也没有改变，因此不是 BLOCKER；建议后续将标签明确为原绑定状态或仅在选择与绑定一致时显示，避免用户误读。此次仅记录，不要求 Coder 即时修改。
