## 草图逐项核对

- 页面框架：固定窄图标导航、简短标题、帮助入口、顶部状态与底部操作区。
- 目标窗口：搜索和刷新同排；后台窗口选项；窗口选择；详情入口；绑定状态和操作。
- 输入方式：执行方式选择；专用模式只保留简短说明；消息模式显示输入类型，指定坐标才显示 X/Y。
- 执行参数：重复间隔标题、帮助、最小/最大值与单位；动态等待说明；永久/限时；限时字段按需显示。
- 诊断：底部更多菜单进入对话框，不保留横跨主内容的诊断折叠条；日志、错误、IPC、回执与执行摘要完整保留。
- 相邻交互：菜单关闭、对话框 Escape 与焦点返回；运行锁定、错误提示和停止入口仍可用。

Verifier 须逐项对照精确草图和 rc.8 基线，而非仅确认新元素存在；没有实测渲染或人工体验时不可写作视觉通过。
