# TASK-013 人工体验步骤

1. 打开目标窗口、输入方式和执行参数页面，确认浅色主题保持不变。
2. 确认输入方式页不再直接展示大段 IPC/身份核验/读取诊断内容。
3. 确认执行参数页的间隔、执行时长和状态信息紧凑可见。
4. 确认目标窗口页搜索与刷新同排，详情通过独立对话框按需查看，绑定状态和操作集中呈现。
5. 点击底部右侧“…” → “诊断信息”，确认打开独立对话框，主页面布局及滚动位置保持；关闭按钮、知道了及 Escape 均可关闭并返回焦点。
6. 在运行、停止和切换页面后确认开始、停止、F8、托盘和现有输入行为保持正常。
7. 消息模式选择中心定位时不显示 X/Y，选择指定坐标后显示；间隔帮助可查看完整限制，主页面仅显示当前等待说明。
8. 在默认大小和缩小窗口下查看字段及底部操作是否可达；限时、自定义坐标等展开内容允许主区滚动，不承诺最小尺寸无需滚动。
