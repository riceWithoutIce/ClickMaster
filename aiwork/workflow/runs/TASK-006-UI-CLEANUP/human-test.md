# rc.1人工体验验收

状态：待本轮稳定候选包及独立审核。开发与审核不自动启动普通UI、查询游戏、注册真实F8或发送；用户按实际可用环境操作，未测项不默认通过。

## UI与基础操作

1. 关闭旧ClickMaster/独立测试器，使用本轮候选包在项目内独立可写测试目录解压运行。启动应待命、无有效绑定，持续时间默认永久；包中没有用户data，运行后数据跟随EXE。
2. 观察目标/输入/执行参数页、顶部摘要与底部操作栏：普通页面无长段技术回执，参数和运行摘要可见；诊断默认折叠，展开后可查看详情，实验预览仅在其中。诊断开关不能触发执行。
3. 筛选并绑定原目标，选择适用通道；如有接收路由歧义，必要选择直接可用。确认执行一次、开始及停止入口易于理解；切页保留草稿。

## 持续时间与结束反馈

1. 先用专用IPC及2000/2000毫秒，选择永久，开始后等待3秒，切到工作窗口，保持目标后台且非最小化。观察已运行计时、本轮次数和游戏响应；正常不会时长到期。按钮/F8/托盘停止任选先测，再按需覆盖其他入口。
2. 选择限时，例如15秒，固定或2000/4000随机间隔。准备3秒期间不计运行时长；进入执行后显示已运行/剩余，包含传输和等待。到期显示时长已到，不开始下一轮，清理期间停止中，结束后保留原因/耗时/次数且不继续增长。
3. 运行中目标/通道/间隔/持续时间不能改。停止后可改，再开始为新一轮、重新准备与计时计数；不是暂停续跑。
4. 检查限时0、空值、非法数值拒绝；时0～99、分秒0～59，不自动进位/夹边。切永久后隐藏限时草稿不阻止开始；执行一次不被重复参数草稿错误阻断。
5. 如需验证边界可用限时1秒、间隔大于时长：到期不再新发，已经发出的帧/消息不能撤回；配对释放和必要清理仍可完成，不以游戏晚处理旧帧判断又发送。无需真实等待99小时。

## 便携与发布检查

按环境选择检查中文/空格目录、从其他工作目录启动、退出后整体移动目录、替换程序并保留data的偏好。所有测试副本和数据放项目内，勿直接在release槽位运行。不要卸载共享WebView2或改变外部软件热键补证。Windows平台/Runtime不足环境、性能测量及其他未测项单独记录。

## 反馈

按[feedback.md](feedback.md)区分视觉、交互、功能问题，关联版本/包hash和具体现象；首次候选人工通过不自动正式发布。确认工作窗口无额外输入、鼠标未移动/目标未抢焦点、到期与手动停止情况；出现干扰立即停止并反馈。真实退出、目标失效、F8冲突等专项按实际执行记录，不要求无目的重复已验流程。
