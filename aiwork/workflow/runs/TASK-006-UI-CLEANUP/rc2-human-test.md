# rc.2人工体验清单

状态：待Coder稳定交接、独立Verifier和用户运行；当前NOT RUN。不代替rc.1历史验收。

## 测试入口

使用本轮新0.1.0-rc.2便携ZIP解压到独立可写目录，保留原rc.1及其data。确认关于页版本，重新选择目标与通道，不自动恢复或执行。真实目标测试由用户操作，不由开发工具启动或发送。

## 最小体验

1. 游戏正常玩法、后台非最小化，执行一次：完整写入时显示已发送一次。展开诊断，可看到读取已确认/未确认/失败等状态；读取结果不等于玩法结果。
2. 使用默认2000毫秒间隔、限时10秒重复：观察已发送次数增长。如果读取未确认或失败，下一轮仍继续；不出现仅因读取确认而执行失败。人工另行观察游戏玩法是否有变化。
3. 执行期间按停止或F8：不再开始新帧，已发送次数保留，结束原因正确；读确认收尾不能长期卡住。托盘沿用原停止入口，最小化继续执行。
4. 未写入成功的连接/目标/写入异常仍停止，并有对应提示；不为验证主动损坏游戏/外部环境，不把未出现情况写作已通过。

反馈最少提供版本、单次/重复、已发送次数、结束原因、读取诊断与玩法有无变化。读取未确认而重复继续符合新约定；玩法不响应需另记兼容性反馈。当前没有高频或逐帧承诺，间隔未放宽。
