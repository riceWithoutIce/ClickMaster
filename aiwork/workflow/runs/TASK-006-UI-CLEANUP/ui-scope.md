## 日常界面

保留现有侧栏及目标窗口、输入方式、执行参数、设置、关于页面。顶部精简为绑定目标与主要运行状态；窗口标题、EXE及PID仍在目标页提供，以满足区分具体实例的需求。

输入页保留通道选择及适用的键鼠/坐标设置。执行页保留最小/最大间隔、等值固定的简短提示和F8说明。底部保留单次、开始、停止、准备/执行/等待/停止状态与工具完成次数；次数不得暗示游戏计数，简短说明可放提示中。避免顶部、底部及结果区重复同一状态。

必要参数不收进诊断：最小/最大间隔、持续时间模式/值及运行进度应在日常执行页直接可用，底部可显示简短参数摘要。rc.1具体布局：顶部绑定目标摘要；目标页保留筛选/后台范围/绑定和必要路由选择；底部集中运行状态、本轮次数、“执行一次/开始/停止”；诊断默认折叠置于操作栏上方，实验预览移入其中；保留侧栏、圆角与轻微动效，不新增UI依赖。

持续时间已确认：模式显示“永久 / 限时”，默认永久（不限时，无自动截止）；限时按时/分/秒输入，总时长1秒～99时59分59秒，拒绝非法值。3秒准备结束后起算，包含实际传输和轮间等待；到期走现有统一停止，不开始下一轮，已发出操作按现有配对释放/在途帧与清理规则结束。运行时按秒显示已运行、本轮次数及限时剩余，永久显示“永久 · 已运行”；结束保留原因、耗时和次数。单次不受重复持续时间影响，不新增次数限制/定时启动/自动恢复。

永久的正常结束由用户通过按钮、F8或托盘手动停止；目标失效、执行异常及实际退出仍按现有规则停止，不因永久模式禁用保护。用户所述“手动暂停”本轮沿用停止语义；再次开始创建新一轮，执行计时/次数重新计算并经过3秒准备，不引入保存进度的暂停/继续状态。最小化到托盘继续执行；关闭并退出后不执行，重启也不自动恢复。

错误仍在操作位置直接显示：目标失效、参数非法、F8冲突、通道不可用、部分投递、超时及清理未确认等。不能因界面精简隐藏失败、将未确认改写为成功，或提前解锁/允许继续执行。

## 诊断信息

采用底部操作栏上方默认折叠的“诊断信息”，集中呈现实际接收窗口/类/路由、按下释放回执、IPC连接/写入/读取阶段、技术错误码及详细原因，不新增诊断导航页。

接收路由存在歧义且需要用户选择时，选择控件仍须在正常绑定流程直接出现，不埋入诊断导致无法继续。诊断开关只影响展示，不触发输入、重绑或重试；不新增持久日志/自动上传。

实验坐标预览从普通输入页移到诊断入口，默认关闭。保留已知问题说明与OVERLAY-001记录，不做覆盖层修复或恢复承诺。

IPC连接/写入/读取超时预算、固定帧及底层客户端说明移入详情/帮助。普通页面仍简述目标需后台且非最小化、专用通道适用范围和不保证任意程序响应；避免常驻长段开发验收说明。

## 回归边界

界面整理保留后端原始状态与区分，输入/停止/身份核验和忙碌门槛不改；已确认的持续时间需另补调度截止与统一取消的实现及验证范围，不作为单纯展示调整交付。独立Verifier对稳定快照核对核心流程与紧邻回归，真实渲染/操作/游戏仍由用户验收。不得将诊断入口移动本身宣称为功能修复。
