- 可确认的项目临时输出及根目录误生成的小型版本命令残留。

## 清单与边界

- prepare.mjs 只生成记录，无删除、移动或外部进程控制逻辑。产物使用相对路径，不记录真实进程 ID、命令行或用户内容。
- `build/verification/TASK-014-WORKSPACE-CLEANUP/preparation/file-plan.json` 为逐文件建议，包含路径、大小、SHA-256 与分类；活动 data 不取固定哈希，不纳入删除集合。大型生成清单放 build，不堆入 workflow 正文。
- historical-versions.json 保存本地候选的现有包指纹、声明比对及验收文档位置，状态为拟淘汰，不伪造正式发布或已删除记录。
- protected-sources.json 记录本次清理前的源码基线，保留 rc.9 原始 manifest，文档后续更新不冒充二进制漂移。
- 执行前重新检查路径仍在仓库内、链接/占用/活动程序和清单指纹；不依据 git ignore 状态批量删除，不结束外部进程。变化或未知对象单独跳过并记录。
- 无需启动产品、真实游戏、输入测试、浏览器或重新构建。
