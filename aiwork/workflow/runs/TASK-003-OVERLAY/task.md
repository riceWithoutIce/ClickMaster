## 目标与方案筛选

基线：R2 已能选择并绑定示例目标，坐标只有界面草稿，没有可视化或输入发送。目标是直接在目标客户区上显示位置，帮助理解坐标。

| 候选 | 优点与代价 | 本轮决定 |
| --- | --- | --- |
| 保留现状/应用内示意图 | 不需桌面窗口，但不能直接对照游戏内容 | 用户选择桌面预览，暂不采用 |
| Tauri 透明 WebView 窗口 | 前端绘制方便，增加 WebView 和窗口管理成本 | 备选，不集成 |
| Rust + Win32 原生覆盖层 | 复用现有 windows-sys，简单图形无需新增 WebView | 用户批准有限 POC |

已核对本地锁定的 Tauri/window API 与 windows-sys 原生窗口 API，未经实机桌面验证。没有浏览器、下载或安装新依赖。

## 本轮范围

1. 现有鼠标坐标区域只增加“显示坐标预览（实验）”开关和简短状态/错误说明，不增加应用内预览画布。默认关闭、本次会话有效。
2. 根据当前绑定窗口的真实客户区显示细边框、十字点击点及客户区宽高/X/Y说明；排除标题栏/边框。沿用中心或自定义整数 X/Y；中心随当前客户区尺寸计算，自定义坐标不按比例缩放。负数、非整数、空值或越界不画误导性有效点击点，给出明确提示。
3. POC 仅在绑定目标是前台且可见、非最小化、非 cloaked、客户区有效时显示；切换其他软件自动隐藏，回目标自动恢复，开关本身不激活目标。不使用覆盖全桌面的常驻置顶窗。
4. 目标移动/尺寸/DPI 变化时刷新边框和标记，多屏负坐标按屏幕坐标处理；仅采样目标几何/身份和必要前台句柄，不枚举或记录其他窗口内容。目标真正隐藏/最小化暂停显示；重新出现可恢复。
5. 原生覆盖层无边框、无任务栏图标、不获取焦点、鼠标穿透；自身及覆盖层不能成为可绑定目标。创建/更新失败需退回可恢复的关闭/错误状态，不能影响主界面。
6. 解绑、重新绑定必须关闭预览，不自动把旧预览切到新实例；绑定失效时关闭。应用退出时释放原生窗口/线程/GDI资源。现有托盘、关闭选择、绑定身份保护和图标保持。
7. 不做点击取点、拖动十字、全局鼠标/键盘监听、截图/录屏、独占全屏保证、输入发送、倒计时、重复执行或热键；既有执行按钮保持禁用。单次测试参数仍待后续对齐。
