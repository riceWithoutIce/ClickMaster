## 目标与范围

- 关联冻结需求 R01、R02 及 R09 的绑定失效部分；本轮使目标窗口页面真正可用，尚不发送输入。
- 列出正在运行的可见应用主窗口，包含最小化窗口，排除自身进程和系统辅助窗口；显示标题、EXE 文件名、PID。支持不同 EXE、同名进程和同进程多个独立主窗口，不按名称合并。
- 初次加载并支持手动刷新，明确加载中、无窗口、失败及权限不足状态。需要满足应用窗口规则且能取得必要进程身份的窗口才可绑定；不可读取项给出必要摘要，不输出完整路径或未经脱敏窗口清单到日志。
- 选择列表项只更新候选，点击绑定后才生效；提供解除绑定。刷新保留仍有效的绑定；失效候选不能借刷新或陈旧请求绑定到重启实例。
- 绑定身份由后端持有，包含窗口句柄、PID 及可验证的进程实例身份；不能仅按名称/PID绑定，不把客户端展示字段当作可信身份。绑定时重新验证，周期检查窗口与进程是否仍有效，窗口关闭或进程退出后清除并提供原因。
- 失效检查在切页和收起到托盘后仍能工作；正常约一秒量级检测，不承诺实时停止，本轮没有输入调度。进程重启后必须重新选择和绑定，不自动跟随同名实例。
- 顶部摘要反映后端真实绑定状态；不激活、移动或修改任何目标窗口，不保存 PID/HWND 为跨启动绑定。
- 窗口右上角关闭按钮 × 改为应用内二级选择框：“收起到托盘”“退出程序”，支持取消、Esc。重复关闭请求不叠加多个框，不默认增加记住选择。
- 收起到托盘沿用现有任务栏保留偏好，托盘不可用或收起失败时保留可恢复窗口并提示；正常最小化按钮行为保持。托盘菜单“退出”直接退出，不反复触发选择框。对话框需基本键盘焦点、取消与错误处理。

- Coder 为唯一源码写入者，继承主会话模型及推理等级；Verifier 对稳定快照只读验收，findings 一次性回用户决定，不直接向 Coder 追加修复。

- 用户仍操作电脑：不启动 EXE、浏览器、开发服务器、可控测试窗口或桌面自动化；不执行真实目标绑定/关闭/激活/最小化，也不以其他原生接口绕过这条边界。实际窗口列表和关闭框交用户验收。
- 所有测试夹具、缓存、临时目录、日志摘要和最终入口留在项目内，遵循 [产物落点](../../generated-data.md)；测试代码新增落点采用本轮任务目录，旧数据测试如需重跑必须先隔离输出。
- 持久记录仅相对路径、脱敏摘要和人工虚构夹具；真实窗口标题、完整进程路径不写入测试报告或日志。读取系统 API 取得的完整路径仅用于内存解析文件名。
- 不提交、推送、发布、清理历史产物、修改全局环境或停止外部进程。
