## 目标选择与绑定

1. 从本轮最终入口运行程序，确认窗口列表展示已有应用的标题、EXE 名称和 PID，ClickMaster 自身不出现。
2. 查看至少两个不同应用；如已有同名进程/同进程多个独立主窗口，确认分别展示且可辨识。最小化窗口仍可在刷新后列出。
3. 选择一个目标，确认顶部尚未绑定；点击绑定后显示正确目标，再切页检查摘要仍在。
4. 刷新列表，仍有效绑定保持；解除绑定后摘要清空。
5. 绑定用户可自行关闭的窗口，关闭后等待状态清除并出现原因；重启同名应用不能自动重新绑定，需重新选择并绑定。
6. 在收起到托盘期间关闭目标，再还原工具，确认已失效。过程中目标不被激活，鼠标不被移动，其他工作窗口不收到输入。

权限不足、无窗口等情况如未实际出现，记录未执行，不补造模拟成真实 Windows 证据。对无关工作窗口的操作由用户判断，验收不要求关闭正在工作的重要应用。

## 关闭选择与紧邻回归

1. 点击主窗口 ×，出现单个收起/退出选择框；取消或 Esc 返回主界面，再次打开不堆叠多个框。
2. 选择收起到托盘，按当前任务栏偏好显示；托盘可还原窗口，正常最小化按钮行为保持。
3. 选择退出后程序退出；再次运行，通过托盘菜单退出也能直接退出。
4. Tab 焦点在对话框内可达；选择目标和切页后关闭框仍可用。
5. 检查侧栏、输入草稿、设置偏好与图标未回退；执行按钮仍禁用，本轮不测试后台输入。

无托盘或收起失败属于单独异常证据，若未触发就保持未执行，不为了视觉验收强行修改系统环境。
