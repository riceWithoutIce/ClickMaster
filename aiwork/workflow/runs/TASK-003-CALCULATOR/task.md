# TASK-003-CALCULATOR：独立内容子窗口数字键自动验证

日期：2026-10-22。用户同意独立内容子窗口单次数字键验证，并要求尽量自动化、减少人工操作。本轮授权限定当前已打开的 Windows 计算器，允许在以下门槛满足后由主协调者运行一次真实单次 PostMessage 测试；不沿用旧任务的全量桌面禁测边界，也不扩大到其他应用或游戏。

## 交付与角色

- 主协调者维护契约、检查稳定交接、汇总一次性 findings、执行获准的单轮实测并记录实际证据。
- Coder 唯一写入测试脚本与说明：`build/verification/TASK-003-CALCULATOR/coder/`；本轮不得修改产品源码、既有脚本或发布产物。
- Coder 可编译、语法/纯逻辑自测，不得真实枚举窗口、调用 UIA 或发送输入；稳定交接后 Verifier 只读审查发送门槛、一次性和落点/脱敏，可以静态/纯逻辑验证，不进行真实桌面测试。
- 任务记录为本目录 `coder-handoff.md`、`verifier-report.md`；原 TASK-003 源码快照及历史证据保持原状。本轮运行角色与既有独立验收必须分开，不冒充全套产品验证。

## 独立工具契约

1. 不下载依赖，优先使用已有 Windows PowerShell/.NET 与系统 Windows UI Automation 只读接口。所有脚本、编译中间物、临时文件、报告都在本轮工作目录，启动任何编译子进程前设置进程级 TEMP/TMP/TMPDIR，不改变全局配置。命令在仓库根执行。
2. 自动发现当前已打开的计算器：仅筛选 ApplicationFrameHost 的 ApplicationFrameWindow 且标题精确为“计算器”或“Calculator”，再找 Windows.UI.Core.CoreWindow 内容子窗口；不保存实际标题、PID/HWND/TID或进程路径。跨进程内容的进程名必须属于明确的计算器名单（如 Calculator/CalculatorApp），并验证其与框架的祖先关系。多个匹配框架允许存在，但可发送的可见、非最小化、非cloaked内容目标必须唯一；否则拒绝。找不到目标不启动应用，不回退其他接收者。
3. UIA 仅用于读取所选计算器内容中的明确结果控件（如稳定 AutomationId CalculatorResults），不 Invoke/SetValue/SetFocus，也不读取其他应用的树。只在结果控件唯一且显示可明确规范化为 0 时允许测试；无法读取或不是 0 都停止，不清空、不尝试准备输入。持久报告仅记录规范化的 0/1/other/unreadable，不保存完整树、历史记录或其他值。
4. 捕获框架及内容窗口 HWND/PID/线程/进程创建时间作为内存快照；倒计时3秒，期间不激活任何窗口。按下前复验原身份、祖先关系、唯一候选与显示值为0，并要求计算器框架及内容均不属于当前前台窗口树；若前台是计算器则停止，不替用户切换工作窗口。不得因倒计时结束重新选择另一实例。可读鼠标位置和前台句柄做前后比较，但仅输出是否相同，不记录真实坐标和外部应用身份；比较不能宣称排除了用户自行操作影响。
5. 键固定主键区1（VK 0x31），只向选定内容 HWND 投递一次 WM_KEYDOWN 和约50ms后 WM_KEYUP，用目标线程键盘布局映射扫描码并正确设置repeat/up位，与产品既定消息语义一致。不发送 WM_CHAR、组合键、鼠标消息，不改变全局键盘设备状态。无重试、循环输入、全局模拟、焦点激活、注入或驱动。
6. 释放前复验原身份/父子关系，仍有效才释放，不向替代窗口补发。异常路径明确区分未发送、按下失败、部分投递与完整投递；按下已成功时用finally尽力对同一仍有效目标完成一次释放，不允许重复释放或在异常时重做按下。目标失效停止。人为终止进程等不作可靠释放承诺。
7. 发送后有界只读轮询（总观察约2秒，次数有上限），用同一结果控件/原身份确认显示为1。输出同时保留API投递结果和实际观察：0→1表示本轮响应证据；仍0表示观察期未响应；读失败/其他值/身份变化/并发用户修改迹象标为无法判定，不将API成功当响应成功。UIA可能阻塞，脚本由父级有界执行；超时后不自动重跑输入。
8. 默认只读/预检，实际投递必须显式参数（例如 -ExecuteOnce），不接受任意按键、消息、目标PID/HWND参数。同一调用只允许一次配对。真实运行报告使用唯一运行编号，不覆盖历史报告；输出先脱敏再落盘，不保存截图或原始异常路径。

## 停止和证据边界

- 仅一轮真实执行；选取/预检拒绝同样记录为未投递，不无限扩展兼容性修复。需要改变目标或消息语义时返回用户对齐。
- Coder 稳定快照后检查冻结清单，再准入 Verifier；findings 一次性返用户决定，禁止边验边修。无阻塞发现后主协调者可执行本契约真实测试，不需重复确认。
- 计算器实测结果不代表 TapTapLoot、所有 UWP/Win32 应用或游戏兼容。鼠标坐标转换和产品子窗口绑定均未实现。
- 前台/鼠标前后相同仅是瞬时辅助证据，不证明全程未变、不证明当前工作窗口没有收到额外输入。UIA读取失败不得升级为其他输入手段。
- 不提交、推送、发布、清理历史或升级依赖；OVERLAY-001 保持延期。
