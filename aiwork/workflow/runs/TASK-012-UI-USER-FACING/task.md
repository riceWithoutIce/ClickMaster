# TASK-012：用户界面整理

日期：2026-10-23。用户已授权先处理已对齐的 UI 体验问题，完成后再进行人工体验反馈。

## 目标

- 将导航栏固定为窄图标导航，不提供展开/收起状态。
- 合并底部运行信息与操作按钮，减少 footer 高度和重复信息。
- 为待命、准备中、运行中、停止中、失败提供稳定的文字与颜色区分；运行中使用绿色。
- 精简目标窗口页的日常信息，保留搜索、后台窗口开关、窗口选择和绑定状态。
- 将 PID、窗口类名、接收窗口、分辨率等技术信息移入按需详情。
- 诊断入口改为按需查看，但继续保留必要日志、错误、IPC 状态、投递结果和执行摘要。

## 范围

- 保留现有页面路由、目标筛选/绑定、输入方式、执行参数、永久/限时执行、开始/停止/F8、托盘和关闭行为。
- 保留诊断内容与项目内日志路径规则，只调整呈现层级。
- 允许更新版本说明和 TASK-012 本地候选包。

- 静态/前端检查确认无导航展开控件，页面仍可访问。
