# 独立IPC桌面测试包

日期：2026-10-22。用户建议直接打EXE包，并明确选择“独立IPC测试EXE：双击打开，由你点击单次或低频测试”。授权开发、构建及独立审核后交付本地测试包；由用户控制真实游戏测试时机，主协调者/Coder/Verifier不自动发送或运行游戏测试。此前脚本测试暂停保留，不恢复旧attempt。

## 技术筛选与决定

基线：已审核C#管道核心+PowerShell监督，原生single已确认读取，但观察时机不方便。候选：

| 候选 | 优势 | 代价/决定 |
| --- | --- | --- |
| 现有C#核心 + .NET 10 WinForms小窗口 | 直接复用协议、身份、调度逻辑；本机SDK/WindowsDesktop运行时/引用包/apphost均已存在 | 仅独立测试器采用；framework-dependent便携文件夹，依赖已装.NET Desktop 10 x64；批准有限实现 |
| 独立Rust/Win32窗口 | 已有Rust及本地缓存，原生分发 | 需重写已验C#管道核心，增加本轮验证成本；延期 |
| 另建Tauri测试应用 | 沿用正式产品UI技术 | 仍需移植IPC/监督、增加前端桥接；不适合仅改善观察操作；延期 |

门槛：Windows x64支持PASS；已装SDK 10.0.300、Desktop引用/运行时10.0.8、win-x64 apphost构建路径PASS；生成/缓存/CLI home/NuGet输出均指向本任务目录，NuGet源清空且不下载新依赖PASS；本任务在build下已被ignore，data全局ignore PASS；无网络/提权/全局安装/产品集成PASS；相对脚本优势为用户自主控制观察时机。决定：在用户已选择的独立EXE范围内实现，不改变正式Tauri选型。不要求单文件打包，允许EXE旁必要DLL/JSON；明确运行依赖，不暗示独立无运行时。

## UI与用户流程

- 简单中文桌面测试窗口，使用项目图标；标明仅TapTapLoot当前已核验版本的内置IPC测试，不宣称任意EXE通用兼容。仅打开窗口不连接管道、不注册F8、不发送、不查询目标，启动保持停止。
- 显示“单次测试”“低频测试（2秒，最多5次）”“停止”与状态/倒计时/写入和读取进度。开始后准备5秒；用户保持游戏可见非最小化且非前台，不自动切换或激活窗口。
- 每次明确点击单次创建新用户测试会话，独立原子attempt；不后台自动重试。单次完成后用户可选择“有响应 / 无响应 / 没看清”，仅当前单次drain成功、正常结束且明确“有响应”才解锁当前会话的低频按钮；反馈与当前run及最终回执绑定，换会话/目标/重启不复用。
- 低频需用户再次明确点击，仍单帧数量1，上一帧drain成功后至少2秒，最多5次，不用数量5替代5次；该会话最多一次repeat。重复点击/重入不允许；新单次会话是用户明确新操作，不自动删除/复用旧attempt。
- 运行期间停止按钮和F8可取消；关闭窗口先停止自有worker并释放热键/句柄后退出，不保留后台发送。UI保持响应，不把同步drain放UI线程。
- 本测试器不要求托盘/偏好/复杂圆角动画，不把临时UI替代正式产品；报错用中文可理解原因，不显示机器路径、票据或原始堆栈。

## 核心运行边界

尽量复用IPC-REPEAT已审核核心，复制入新任务不改旧文件。当前精确TapTapLoot实例/EXE/主程序集SHA、原创建时间及保留查询句柄、唯一UnityWndClass后台可见非最小化有效客户区、逐帧原客户端与窗口身份核验不变；不跟随重启。TypingFarmer管道first-instance/max1/current-user DACL/reject-remote不变。无SendInput/PostMessage、键鼠hook、焦点或光标操作、进程内存/注入/驱动/调试器、游戏文件修改。

F8仅运行期间注册，冲突则不创建worker；UI线程可靠处理WM_HOTKEY，结束注销。每阶段总监督60秒、连接20秒、写2秒、逐帧drain10秒；使用单调时钟与已修UTC精度，系统调度及最多2秒退出等待限制诚实保留。所有停止/失败/失效后不安排下一帧，仅结束直接创建并保留Process对象的自有worker，不杀树/不按名字或PID扫描后终止。内部worker用同EXE受控入口，单次票据与当前会话/阶段/二进制hash/一次claim核验；普通启动绝不成为worker。同步drain阻塞由监督隔离结束解除。在途帧不可撤回，不冒称未发。

逐帧write-attempted/completed/drain-started/completed原子回执、正常Dispose与OS回收/退出未确认分别保留。终态保守，不把读取成功当游戏解析/玩法/统计等价，也不把取消/超时当未读取。用户反馈单独持久化，不改写原worker/supervisor回执。

## 构建、数据与交付

- 唯一源码写入：`build/verification/TAPTAPLOOT-IPC-EXE/coder/`。新csproj与构建脚本全部在此，输出obj/bin/cache/temp/CLI home/NuGet本任务内。显式清空包源，关闭telemetry/first-run/workload广告，不装新工具。使用已装SDK/refpack/apphost；离线缺依赖则报告，不擅自下载。
- framework-dependent Windows x64便携文件夹，双击 `ClickMaster.IpcTest.exe`；同目录必要DLL/JSON/中文说明保留，不要求单文件。使用项目icon，构建禁PDB/绝对源码路径元数据或做PathMap。最终测试包放本任务 `coder/final/`，不晋级release，不覆盖staging旧物。
- 运行数据基于实际EXE位置，同级 `data/`：会话/日志/临时文件，不依赖CWD，不回退C盘用户目录，不可写则提示停止。启动worker前设置TEMP/TMP/TMPDIR到data内。数据/原始凭据不入包，文档/回执不落真实PID/HWND/绝对路径/个人窗口标题。
- 日志和会话最多保留10个用户会话，达到上限提示用户处理，不能无限自动增加；本轮不自动清理任何既有数据。UI明确会话包含single及其repeat，用户关闭后不恢复有效绑定/确认。只有实际发送才消耗阶段attempt，前置开始失败亦保留当前attempt。
- 包说明解释.NET Desktop 10 x64依赖、本机已具备；不自动下载/安装。标明5秒准备、先单次确认再低频、停止/F8、后台窗口要求、读取与实际响应区别，以及带着必要文件运行。

## 验证与角色

Coder完成编译及共用核心/调度/阶段门槛/停止/时间/回执/路径边界的相称纯回归，提供可执行的无GUI纯自检入口；该模式不查询游戏、注册F8、启动worker、创建真实管道或发送。只能在任务内运行，产物脱敏。原生UI渲染、真实热键送达、游戏效果由用户验，不由自动打开工具替代。

稳定快照需包含源码清单/hash、最终EXE及必要文件hash、构建命令、依赖说明、纯测试结果及未执行项。独立Verifier冻结后只读审核核心流程与已声明交付证据，可在自己的目录独立构建/纯测试，不自动启动UI/游戏/热键/发送。findings集中交用户裁定，不给Coder追加工作。主协调者核对包与保留manifest后提供可点击EXE路径，不自动启动或实测。无提交/推送/正式发布/旧证据清理。
