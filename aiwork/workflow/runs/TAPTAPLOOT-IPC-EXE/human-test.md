# 用户桌面验收

适用：本轮独立IPC测试包；待稳定产物和独立审核完成后执行。由用户决定何时运行，不自动打开EXE、游戏或发送。

## 最短测试流程

1. 保留测试包内全部文件，双击 `ClickMaster.IpcTest.exe`。打开后应保持待命，没有自动测试、游戏抢焦点或鼠标移动。
2. 游戏进入正常玩法，保持可见、非最小化且非前台。点击测试器“单次测试”，留意5秒准备提示；随后暂停真实键鼠。游戏可能把点击测试按钮本身也计数，所以只判断倒计时结束后发送时的变化，不把按钮点击的变化当作IPC效果。
3. 工具中“写入完成 / 读取完成”是传输状态；只有你观察到计数或玩法变化，才选择“有响应”。没看清时选择对应选项，不用猜测，也不用提前回复一个计数。
4. 本次单次正常完成且明确有响应后，点击“低频测试”。每次数量1、至少2秒间隔、最多5次，实际进度应与读取状态分开显示。观察响应是否持续及工作窗口是否有额外输入。
5. 需要停止时点击“停止”或按F8；关闭测试器也应结束当前测试。停止后的在途数据可能已经生效，不能撤回。F8本身是真实按键，不将取消时计数作为精确IPC数量对照。

## 记录口径

- 分别记录窗口操作、单次可见响应、低频可见响应、停止按钮、F8实际停止和关闭退出；未测试的项保留未验。
- “读取完成”不代替游戏效果；“没看清”不等于失败；5次有效不等于长期稳定或任意程序兼容。
- 数据只应在EXE同级 `data/`，重开不恢复有效绑定或解锁状态。最多10个会话，达到上限提示处理，不自动删除用户数据。
- 游戏重启/窗口变化后，应重新做当前单次确认；测试器不自动跟随。F8冲突应阻止开始。
- 若出现抢焦点、真实鼠标移动、工作窗口收到额外输入或工具退出后继续触发，停止测试并反馈，保留data；不要自动增加次数或尝试其他输入方式。

结果待用户实际反馈；本清单不代表上述真实桌面条件已经通过。
