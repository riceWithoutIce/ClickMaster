# AI 调试记录

此目录保存问题复现、调查过程、修复依据与复验结果。目前没有实际调试记录。

## 命名与内容

- 从 [_template.md](_template.md) 复制创建，命名为 `YYYY-MM-DD-简短问题名.md`。
- 一条记录聚焦一个问题，区分已观察事实、待验证假设和已执行动作。
- 命令注明仓库相对执行位置；路径使用仓库相对路径。
- 记录源码快照或版本、环境、预期与实际结果、证据位置、结论及剩余限制。
- 没有执行的检查标记“未执行”；无法判断时标记“证据不足”。
- 不将 PostMessage 投递成功记为游戏玩法通过；三种输入方式分别记录。
- 日志只保存必要片段，大型产物与缓存的目录及保留方式在实际生成前明确。
- 保存前按 [脱敏约定](../workflow/sanitization.md) 处理本机路径、个人信息、凭据及截图，禁止直接归档未脱敏原始输出。
- 不为调查自动扩大输入技术、启动无关程序或修改其他项目。

阶段性结论同时追加到 `../devlog.md`，涉及里程碑时更新 `../roadmap.md`。
