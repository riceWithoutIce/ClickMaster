# 0.1.0 已知限制与证据边界

`0.1.0` 验收包已获用户人工回归通过并获准正式发布；签名状态、产物指纹和发布提交以配套来源记录及发布索引为准，不扩大未验证范围。

## 输入与目标兼容性

- 窗口消息是否生效取决于应用，成功投递不等于玩法响应。TapTapLoot 的消息键鼠已知无效；计算器内容子窗口单次数字键有早期人工通过记录，不能推广到其他窗口或输入。
- TapTapLoot 专用 IPC 仅适用于已核验的程序/程序集版本和协议；不提供通用游戏适配。历史人工验收已确认专用 IPC 的单次、重复、前后台交互和停止；连接复用后 loading 光标问题人工通过。`0.1.0` 包已按交付清单完成人工总体回归，不推定其他目标或输入方式通过。
- 不移动真实鼠标、不主动抢焦点，不使用全局 SendInput、输入 hook、DLL/代码注入或驱动。失败后不自动重绑、不切换通道、不重连或重发。
- 目标要求非最小化，专用 IPC 还要求目标窗口可见；不承诺目标最小化兼容。本工具自身可收起到托盘继续运行。
- 鼠标坐标是客户区像素，移动窗口不改变相对位置，缩放不自动比例定位；映射后的消息坐标不得超过 32767。

## 执行频率与停止

- 两通道的间隔范围均为 1～60000 毫秒，默认 2000/2000；间隔为完整操作后的额外等待，不等于固定发送频率或帧同步。1 毫秒仅用于边界测试，不承诺 1kHz 或每秒 30/60 次玩法响应。消息按下/释放另有约 50 毫秒配对间隔。
- IPC 的“已发送”指完整写入一帧，不能当作游戏计数。单次路径保留最多 200 毫秒读取观察，重复路径复用本轮 worker/连接且不要求读取确认；读取结果只作诊断，不阻断循环。
- IPC 有限管道缓冲可能积压，原生单帧写入最多等待约 2 秒后超时停止，无无界应用层队列。旧静态消费者证据约每次读取前等待 90 毫秒，不代表本版实际消费频率。
- 停止或到期后不开始新操作；已投递消息和已写帧无法撤回，游戏可能继续处理已有缓冲，断开时也可能丢失未读帧。不承诺可靠送达或瞬间清空目标输入。
- 限时从 3 秒准备结束起算，包含操作和等待；配对释放及自有 worker 清理需要时间。清理未确认保持锁定，不算正常完成。不自动结束无关外部进程。
- F8 注册冲突时拒绝开始；永久模式仍受目标失效、身份变化和执行异常保护。无长按、组合键、脚本、暂停续跑、自定义热键、自动更新或安装器；执行参数仅会话保存，重启不恢复绑定或执行。

## 已知延期项

- OVERLAY-001：实验坐标覆盖层有未显示反馈，保留在诊断中，不代表已修复。
- F-01：绑定 A 后选中 B，列表下方“已绑定”标签可能仍表示 A；顶部和实际绑定仍是 A，选择 B 不会自动换绑。需点击“绑定窗口”才切换目标。
- 性能 FOLLOW-UP：文件回执、逐帧完整核验、消息等待检查、待命/隐藏轮询和持久 worker 阶段统计覆盖仍有优化空间。非游戏测量不能推导真实游戏或完整产品资源降幅，未冻结 CPU/内存上限。
- V008-01：历史热键测试曾因终态完成同步窗口失败，后续通过不抹去原失败；测试同步修复继续延期，未证实生产停止功能回归。

## 系统、数据与诊断

- 面向 Windows 10 22H2 / Windows 11 x64，使用共享 Evergreen WebView2；建议使用当前受支持版本。完整功能的最低 WebView2 版本、Windows 11、缺失/旧 Runtime、跨系统与长期资源专项没有本版实测证明。缺失或初始化失败时不自动安装、提权或更改其他软件的共享 Runtime。
- 当前包未签名，Windows 可能提示；校验来源与 SHA-256，不保证重建字节一致。构建时工作区指纹、基线提交与正式发布提交分别记录；随包文档保留验收时的准备状态说明，正式晋级以 Release、来源文件和索引为准。
- 项目数据保存在 EXE 同级 `data/`，需要目录可写，不自动回退用户目录。OS/共享 Runtime 的内部记录由系统管理，不承诺全系统零外写或永不联网。
- 同目录多实例/共享 data 没有新增互斥保证，建议只运行一个副本；管道占用时停止且不重试。WebView 缓存可能增长，异常 IPC 槽位不会在启动时批量清理。升级保留 `data/`，不在运行中删除未知文件。
- 性能日志默认关闭，手动采集最多 60 秒，单次不超过 1 MiB，最多 5 套/5 MiB；中断、慢盘或退出可能留下有界不完整记录。采集有自身开销，CPU、工作集和阶段墙钟不是同一指标。
- WebView 环境列表可能跨实例/应用共享，不含 crashpad，不是本 EXE 独占总量；工作集求和可能重叠。列表最多 64 项、2.5 秒过期，短命进程与峰值可能漏采；首次基线、接口不支持、访问失败、成员变化或过期保留缺失/部分覆盖，不补零。
- 持久 worker 跨采集边界或尚未结束时阶段统计可能缺失。状态切换区间标 mixed、未知标 unknown，未观察组不补零，末尾不足一秒不纳入严格分组；总会话指标可能与四组之和不同。CPU 百分比按整机口径及各分项实际观察时长计算，部分覆盖只表示观察下界，不能推算独占总量。
