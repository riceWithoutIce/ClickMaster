# 0.1.0-rc.7 已知限制与证据边界

- 窗口消息是否有效取决于应用，入队不等于响应；TapTapLoot消息键鼠已知无效，计算器内容子窗口单次键盘有旧版人工通过回执。
- TapTapLoot专用IPC限已核验实例/程序集版本及原协议；旧版人工回执确认响应、固定/随机重复、按钮/F8/托盘停止。rc.1曾有写入完成但读取未确认的失败反馈；rc.2改为完整写入即已发送，读取结果仅作诊断，仍需本轮人工体验，不宣称通用游戏适配或已修复全部rc.1根因。
- IPC写入成功不保证目标消费或玩法响应。单次保留200毫秒读取观察及有界清理；rc.7重复运行复用一个worker/连接，每帧核验后直接写入，读取确认不阻断执行。停止、断开、身份变化和写失败停止并清理，不重连/重试/回退。
- rc.7允许消息与IPC均设置1～60000毫秒间隔，默认仍为2000/2000；1毫秒仅是极限输入边界，不承诺1kHz。间隔是单次操作完成后的额外等待，不等于每秒固定次数或与游戏帧同步。实际频率受系统调度、身份核验、传输与游戏处理耗时影响。
- 持久连接可积压已写帧。旧静态消费者证据显示每次读取前等待约90毫秒，不代表本轮实测频率；极短间隔可能快于消费。原生单帧写入保留2秒超时和取消退役，没有无界应用层队列；已发缓冲帧不可撤回，停止后游戏仍可能继续处理，清理时也可能丢失未读帧。不承诺可靠送达或停止瞬间清空游戏消费。
- 不移动真实鼠标、不主动抢焦点、不用全局SendInput/键鼠hook/注入/驱动；不自动重绑/重试/切通道。完整工作输入隔离、退出/目标失效等发布专项仍需人工证据。
- 专用IPC可前台或后台运行，人工交互与自动效果可能叠加；仍要求目标可见且非最小化。消息通道行为不变。不承诺最小化兼容。鼠标采用客户区像素，不做比例定位，映射后不能超过32767。
- rc.7重复路径将EXE/程序集哈希、授权与建连移到本轮worker准入，原实例/唯一性和客户端仍每帧写前核验。减少重复启动不等于消除全部开销；非游戏fixture测量不代表完整Tauri/WebView2或真实游戏资源降幅。真实鼠标loading、前后台交互、持续运行和资源仍需本轮人工验收。
- 限时准备结束起算，含操作和等待，到期不新发；已发帧不可撤回。配对释放/自有Child清理有耗时，不承诺精确毫秒停止；失败、部分投递、清理未确认不算正常到期。
- 无长按、组合键、脚本、暂停续跑、参数持久化、自定义热键、自动更新或安装器。F8冲突拒绝开始；永久模式仍保留目标失效和执行异常保护。
- 覆盖层OVERLAY-001延期，入口移诊断不表示修复。
- 支持目标Windows 10 22H2 / Windows 11 x64；当前静态/fixture证据不代替跨系统、真实UI、缺失/旧Runtime及启动/资源测量，缺证据标NOT RUN。锁定组合所有功能所需的最低WebView2版本未独立证明，建议使用当前受支持Evergreen，不把存在Runtime当作功能兼容证明。
- OS/共享Runtime自身记录由系统管理，不承诺全系统零外写或永不联网；同目录多实例/共享data无新增互斥保证。WebView缓存不保证固定大小，异常IPC槽位不会启动时批量清理。
- 当前仅本地候选，未正式晋级。源码/hash关联dirty快照，不等同Git提交或签名，不保证重建字节一致；多轮RC后仍需明确正式发布授权。
- rc.5增加可选60秒诊断；rc.6补充WebView环境观测和四状态对照，未同时实施新IPC优化。日志包含自身采集开销；非游戏比较不能证明零开销或真实游戏性能。主程序内存为每秒快照，worker CPU来自原Child句柄；跨采集边界和中断的阶段统计会截断。退出最多等待日志线程250ms，慢盘/异常退出可能留下有界不完整记录；不会为采集停止连点或清理未知日志。
- WebView环境列表按同一用户数据目录归组，可能跨实例/应用共享，不含crashpad。环境CPU/内存不是EXE独占总量，工作集求和可能重叠；列表最多64项、2.5秒过期，短命进程可能漏采。接口不支持、访问拒绝、成员变化、首次CPU和过期均保留缺失/部分覆盖，不补零，不以名字/父进程扫描替代。真实COM、共享环境、多系统与四状态真实运行证据尚待人工采集，模拟adapter/native句柄测试不能代替。
- 四状态只汇总完整采样区间，切换穿过区间标mixed，未知不强行归组，末尾不足一秒部分不纳入分组；总会话发送量/CPU可能因此与四组之和不同。CPU百分比为整机口径、按各分项实际观察时长计算；部分覆盖仅为观察下界，不能推算独占总量。
