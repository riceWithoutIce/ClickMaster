# 前端源码

按已确认的 Tauri 官方常用布局，`src/` 只承载 TypeScript、样式、组件及前端资源；Rust 后端位于根级 [src-tauri/](../src-tauri/README.md)。

前端工程配置、`package.json`、`index.html` 和 `package-lock.json` 位于仓库根。从仓库根经 `scripts/npm.ps1` 执行命令。`App.vue` 提供侧栏二级页面：连点控制下的目标窗口、输入方式、执行参数，以及设置、关于；顶部目标摘要与底部运行控制常驻。局部页面状态保留本次会话的输入模式、中心选项和坐标草稿，不增加持久化或路由依赖。`NavIcon.vue` 为少量本地线条图标，`main.ts` 初始化 Vue，`style.css` 包含基本响应式和减少动效支持。具体依赖固定在 package.json 与锁文件。

圆角和UI动效由前端负责；前端编译输出为 `build/frontend/`。应用信息、最小化偏好、真实候选列表及绑定状态通过Rust IPC读取/操作；候选只持后端token，不回传展示字段冒充可信身份。窗口关闭选择使用原生HTML dialog，取消默认焦点、Esc和键盘焦点约束；不持久化关闭选择。单次测试/取消已启用，重复执行及全局停止仍禁用。

目标页支持按EXE、标题、PID即时部分匹配，忽略大小写和输入首尾空白；显示匹配/候选数量及可见、最小化、隐藏状态，无标题使用占位说明。隐藏/后台范围默认关闭，切换后重新查询。筛选词及范围和其他草稿保留在根级会话状态，不改变配置格式；刷新重置未绑定候选选择以取得新token，过滤掉的选择立即清空，后端有效绑定不受过滤影响。`target-filter.ts`为实际使用的纯辅助函数，经现有TypeScript编译器离线测试，不启动浏览器。

源码历史通过 Git 追溯，不保留按版本复制的代码、发布包或编译缓存。文件内容遵循 [脱敏约定](../aiwork/workflow/sanitization.md)。

鼠标位置区域的“显示坐标预览（实验）”通过IPC控制独立原生窗口，前端不绘制桌面画布。沿用中心/X/Y草稿，`overlay-position.ts`将空值与非有限值转为null，负数/小数交后端显示无效提示。仅会话内启用，默认关闭；状态有单调revision用于处理事件/轮询乱序，草稿变动短暂合并后同步，绑定代次变化取消待发更新。切键盘输入关闭预览；切页保留草稿。目标切到前台才显示，应用不会自动激活目标。关闭/错误状态取消待发更新，不自动恢复失败预览；用户可重新开启。

`single-input.ts`定义键盘下拉42项（默认空格）及倒计时/阶段结果文案。单次按钮只提交模式/按键/位置草稿及预期绑定epoch，目标身份由后端读取；期间禁用模式/按键/坐标草稿及再次测试，导航仍可用。倒计时来自Rust事件和状态轮询，不由页面计时器驱动；切页或托盘收起不重启任务。底部结果保留当前/最近任务、按下/释放投递与错误码，明确已投递需人工确认响应，部分失败不报成功。“取消单次”不代表全局停止热键。OVERLAY-001已知未显示问题保持延期；输入独立计算坐标，不依赖覆盖层。

`receiver-routing.ts`统一接收对象显示和就绪门槛。顶部及目标页区分绑定窗口与实际接收窗口，展示EXE、PID、类、尺寸和自动/手动/自身/待选/失效；多个内容候选必须明确确认后端token，未就绪禁用单次。请求同时携带绑定与接收epoch，接收身份只由后端获取。鼠标X/Y始终以绑定客户区为准，后端转换并拒绝接收区域外坐标。底部每次结果保留当次接收摘要，之后换绑不会重写旧receipt的接收对象。
